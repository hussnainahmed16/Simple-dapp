# Simple dApp Project

A basic dApp connecting HTML/JS to a Solidity contract on the Sepolia testnet.

## Contract Information
- **Network:** Sepolia Testnet
- **Contract Address:** PASTE_YOUR_SEPOLIA_CONTRACT_ADDRESS_HERE

## How to Run
1. Deploy `SmartContract.sol` in Remix on the Sepolia network using **Injected Provider - MetaMask**.
2. Copy the deployed address and paste it into `CONTRACT_ADDRESS` in `index.html`.
3. Open `index.html` in your browser.
4. Click **Connect Wallet**, then test the **Read** and **Update** buttons.
